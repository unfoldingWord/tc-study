# @bt-synergy/language-pack-assistant

The assistant without a model for language packs format 3. It turns a question in Spanish, Portuguese or English into a call of
one of the eight queries of `@bt-synergy/language-pack-client` (`passage`, `concept`, `article`, `renderings`, `search`, `topics`,
`books`, `context`) using fixed phrases, rules, stems, a small naive Bayes classifier and full-text search only, and it shows the
answer it finds in the installed packs as a card of pieces (verses, notes, articles, renderings, ...). It never calls a model and
never reaches a network: it reads the installed packs through a `PackReader`.

The main entry (`src/index.ts`) imports no Node module (`src/entry.test.ts` follows its import graph). `build/` and `eval/` use Node
and Bun and are not part of the entry.

## Use

```ts
import { createAssistant } from '@bt-synergy/language-pack-assistant'

const assistant = await createAssistant({ reader, tag: 'es-419', complements: [numbersBytes, classifierBytes] })
const card = await assistant.ask('que dice Tito 2:11')
card.decision        // { kind: 'call', call: { query: 'passage', args: { ref: ... } }, via: 'rule', interpretation }
card.pieces          // fragments with ids such as `verse:glt tit 2:11`
const other = await assistant.run(call) // the card of a call the person chose from a `choose` decision
```

`reader` is the client's reader of one language (open one at a time: the lexicon, last verses and names are built once in
`createAssistant`). `tag` is the language of the question; its base (`es-419` -> `es`, `pt-BR` -> `pt`, `en`) picks the stems,
phrases, templates and complements. Another base gets rules and search only. `complements` are the bytes of the files in
`complements/`; a file for another `queries/N`, or that does not parse, is not used and is listed in `assistant.problems` as
`{ code: 'E_COMPLEMENT', kind, lang }` (never thrown).

## The chain (`decide`)

1. Rules over the question's entities (references, concepts, Strong keys, books, number words): the decision is a `call` with
   `via: 'rule'`.
2. The classifier over the masked question (entities replaced by their slot words): taken alone when its best probability leads the
   second by `DEFAULT_MARGIN` (0.3), `via: 'classifier'`.
3. Below the margin, the two best queries become a `choose` decision for the person to pick from.
4. Search as the fallback (`via: 'search'`): the chain did not decide. The card sends the question's content words, and each one
   alone when nothing is found.

A decision carries `interpretation`, one line of what was understood, in the question's language.

## Files

- `src/`: the chain, the lexicon, the rules, the card and the fragments. `index.ts` is the public surface.
- `complements/<lang>.numbers.json` (number words, generated by `build/numbers.ts` from `cldr-rbnf`) and
  `complements/<lang>.classifier.json` (generated by `build/train.ts` from `templates/<lang>.json`); a rerun gives the same bytes.
  Header: `{ kind, lang, version, for: 'queries/1', ... }`.
- `eval/`: the evaluation harness. See `eval/README.md`.

## Tests
