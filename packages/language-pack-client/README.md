# @bt-synergy/language-pack-client

Common client library of language packs format 3: it installs, updates and queries packs on top of `@bt-synergy/language-pack-v3`, with a memory store and a Node file store (`@bt-synergy/language-pack-client/node/fsStore`). The main entry imports no Node module, so it runs in browsers, WebViews, Cloudflare Workers and Bun.
